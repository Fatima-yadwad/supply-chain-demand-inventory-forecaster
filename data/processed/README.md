# Processed Data

## cleaned_inventory.csv

This file contains the cleaned and preprocessed retail inventory dataset generated by the data preprocessing pipeline.

### Dataset Information

- Source: Retail Store Inventory and Demand Forecasting (Kaggle)
- Original records: 76,000
- Processed records: 76,000
- Total columns: 26
- Target variable: `demand`
- Forecasting target: `target_demand`

### Processing Performed

1. Standardized column names into snake_case.
2. Converted dates into datetime format.
3. Removed invalid records and duplicate rows.
4. Selected `Demand` as the forecasting target.
5. Generated calendar features.
6. Generated demand lag features.
7. Generated a seven-observation rolling demand mean.

### Engineered Features

- `year`
- `month`
- `day`
- `day_of_week`
- `week_of_year`
- `is_weekend`
- `demand_lag_1`
- `demand_lag_7`
- `demand_rolling_mean_7`

### Generation

Run the following command from the project root:

```bash
python -u scripts/run_eda.py
```

The processed CSV is generated automatically and is excluded from Git using `.gitignore`. It should be regenerated locally from the original dataset when required.
